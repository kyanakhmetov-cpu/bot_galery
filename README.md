# 🎨 Бот для ежедневных постов с искусством в Telegram

Каждый день автоматически публикует случайную работу из открытой коллекции
**The Metropolitan Museum of Art** в ваш Telegram-канал по шаблону:

> Художник — Название (техника, год)

Всё работает бесплатно на GitHub Actions — свой сервер не нужен. Картинки берутся
только из общественного достояния (CC0), поэтому их можно свободно публиковать.

---

## Что нужно сделать (один раз, ~10 минут)

### Шаг 1. Создать бота

1. Откройте в Telegram бота **@BotFather**.
2. Отправьте команду `/newbot` и придумайте имя и username бота.
3. BotFather пришлёт **токен** — длинную строку вида `1234567890:AAH...`.
   Сохраните её, она понадобится дальше. Никому не показывайте этот токен.

### Шаг 2. Добавить бота в канал администратором

1. Откройте свой канал → **Управление каналом** → **Администраторы** →
   **Добавить администратора**.
2. Найдите своего бота по username и добавьте его.
3. Включите ему право **«Публикация сообщений»** (Post Messages).
   Остальные права можно отключить.

### Шаг 3. Узнать идентификатор канала

- **Публичный канал** (есть @username): идентификатор — это `@username` вашего
  канала (например `@MyArtGallery`). Это самый простой вариант.
- **Приватный канал** (без username): нужен числовой ID вида `-100xxxxxxxxxx`.
  Чтобы его получить — добавьте в канал бота **@username_to_id_bot** (или
  перешлите ему любой пост из канала), он покажет ID.

### Шаг 4. Создать репозиторий на GitHub и загрузить файлы

1. Зарегистрируйтесь/войдите на https://github.com и нажмите **New repository**.
   Назовите его, например, `art-bot`, оставьте **Private**, создайте.
2. Загрузите в репозиторий **все файлы из этой папки**, сохранив структуру:
   ```
   art-bot/
   ├── post_artwork.py
   ├── requirements.txt
   ├── README.md
   └── .github/
       └── workflows/
           └── daily-art.yml
   ```
   Папку `.github/workflows/` обязательно сохраните — именно в ней GitHub ищет
   расписание. Файлы можно перетащить через **Add file → Upload files**
   (создайте папки, набрав путь `.github/workflows/daily-art.yml` при загрузке).

### Шаг 5. Добавить секреты (токен и канал)

В репозитории: **Settings** → **Secrets and variables** → **Actions** →
**New repository secret**. Создайте два секрета:

| Имя секрета | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен из Шага 1 |
| `TELEGRAM_CHANNEL` | `@username` канала или числовой `-100…` ID |

Секреты хранятся в зашифрованном виде и не видны в логах.

### Шаг 6. Проверить прямо сейчас

1. Вкладка **Actions** → выберите слева **Daily Art Post** → кнопка
   **Run workflow** → **Run workflow**.
2. Через минуту в канале появится первый пост. Если что-то пошло не так — откройте
   запуск и посмотрите красный шаг: текст ошибки подскажет причину (чаще всего —
   опечатка в секрете или боту не выдали право на публикацию).

Готово! Дальше пост будет выходить **каждый день автоматически**.

## Как поменять время публикации

Откройте файл `.github/workflows/daily-art.yml` и измените строку с `cron`.
Время задаётся в **UTC** (Франкфурт = UTC+2 летом / UTC+1 зимой). Примеры:

- `"0 7 * * *"` → 07:00 UTC (~09:00 во Франкфурте летом)
- `"0 9 * * *"` → 09:00 UTC (~11:00 во Франкфурте летом) — по умолчанию
- `"30 17 * * *"` → 17:30 UTC (~19:30 во Франкфурте летом)

## Как настроить содержание

В начале файла `post_artwork.py` есть блок **НАСТРОЙКИ**:

- `SEARCH_TERMS` — список тем, из которых берутся работы. Добавляйте свои слова,
  чтобы сделать ленту разнообразнее.
- `PREFER_WALL_ART` — если `True`, бот предпочитает живопись и графику (как в
  галерее). Поставьте `False`, чтобы постить вообще любые экспонаты.
- `ADD_SOURCE_LINK` — добавлять ли ссылку на работу на сайте музея.

## Полезно знать о GitHub Actions

- Бесплатных минут на приватный репозиторий хватает с огромным запасом
  (один такой запуск — меньше минуты в день).
- Запуск по расписанию может задержаться на несколько минут — это нормально для
  GitHub.
- Если в репозитории **60 дней не было активности**, GitHub автоматически
  останавливает расписание и присылает письмо. Любой коммит или ручной запуск
  снова его включает.
- Расписание работает только в основной ветке репозитория (`main`).

## Запуск на своём компьютере (по желанию, для теста)

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="ваш_токен"
export TELEGRAM_CHANNEL="@ваш_канал"
python post_artwork.py
```

## Идеи на будущее

- **Без повторов.** Сейчас работа выбирается случайно (коллекция огромная, так что
  повторы крайне маловероятны). При желании можно сохранять ID опубликованных
  работ в файл и коммитить обратно в репозиторий.
- **Подписи на русском.** Данные музея на английском. Можно добавить шаг перевода
  названия/техники.
- **Другие музеи.** Похожие открытые API есть у Art Institute of Chicago,
  Rijksmuseum, Cleveland Museum of Art — их можно подключить как дополнительные
  источники.
